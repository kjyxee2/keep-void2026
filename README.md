# RE:FIT

> 덜 버리고, 다시 만들다.
> VOID 2026 해커톤, 팀 한산

안산 산단 공장의 폐기물이 지금 어디로 가는지 보여 주고, 이웃 공장들이 이미 쓰고 있는 재활용 처리업체로 연결해 처리비와 소각, 매립을 줄이는 서비스입니다.

## 문제

안산 공장들은 해마다 폐기물 약 55만 톤을 처리업체에 맡기며 연 900억원 안팎(추정)을 내지만, 내 폐기물이 어디로 가서 어떻게 처리되는지, 이웃 공장은 같은 폐기물을 어디서 재활용하는지 볼 수 없습니다.

| 데이터가 보여 주는 것 | 숫자 | 기준 |
|---|---|---|
| 안산 밖으로 나가는 신고 경로 | 위치 확인 경로의 81.2% | 2026-07 신고 4,575건 |
| 안산 안에서 처리 | 17.1% (2023년 18.7%) | 신고 건수 |
| 태우는 처리 대 원료 재활용 | 33.3% 대 27.7% | 신고 건수 |
| 같은 폐기물인데 이웃은 재활용, 우리는 소각 | 26.6% | 신고 건수 |
| 공장당 처리업체 | 평균 3.08곳과 따로 계약 | 신고 건수 |
| 공장 폐기물 위탁 처리량과 처리비 | 54만 9천 톤, 연 약 915억원(519억~1,488억원) | 2024, 추정 |
| 경기 비교 | 매립량 31개 시군 중 1위 | 2024 |

흐름 비율은 신고 건수 기준이며 톤수가 아닙니다.

## 해결

| 기능 | 하는 일 |
|---|---|
| FIT MAP | 안산 공장 폐기물이 지금 어디로, 어떤 방식으로 가는지 지도로 보여 줌 |
| FIT 점수 | 같은 폐기물을 이미 재활용으로 보내는 이웃 공장 수, 거리, 처리 방식으로 재활용 처리업체를 점수화해 상위 3곳 추천 |
| GROUP FIT | 같은 폐기물을 내는 인근 소량 공장을 묶어 공동 수거와 공동 계약 |
| FIT REPORT | 공장에는 예상 절감액, 시에는 소각과 매립 회피, 안산 안 재활용 비율 변화를 보고 |

## 핵심 흐름

홈 → 1분 진단(품목, 물량, 위치) → 결과(지금 내는 돈, 추천 3곳) → 연결 요청 → 내 공장

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `data/refit_demo_data.zip` | 시연 데이터. 압축을 풀면 `demo/` 폴더(공장, 처리업체, 신고 경로, 추천 후보, 공동 수거 묶음, 단가, 요약 지표). 열 정의와 Supabase 가져오기 방법은 `demo/README.md` |

## 기술 스택

Next.js(Vercel), Supabase(Postgres, Auth, Storage)

## 한계

- 흐름은 신고된 계약 경로이며 실제 운반 실적이 아닙니다.
- 처리 방식은 처리업체의 허가 업종으로 추정했습니다.
- 금액은 품목별 단가를 곱한 추정치입니다.
- 추천은 신고 경로를 근거로 하며, 실제 처리 가능 여부는 업체 확인이 필요합니다.
