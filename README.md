# RE:FIT

> 안산에서 나온 자원, 다시 안산으로.
> VOID 2026 해커톤, 팀 한산

안산 산단 공장의 폐기물이 지금 어디로 가는지 보여 주고, 이웃 공장들이 이미 쓰고 있는 재활용 처리업체로 연결해 소각과 매립을 줄이는 서비스입니다.

## 문제

안산 공장들은 폐기물을 처리업체에 맡기지만, 내 폐기물이 어디로 가서 어떻게 처리되는지, 이웃 공장은 같은 폐기물을 어디서 재활용하는지 볼 수 없습니다.

| 데이터가 보여 주는 것 | 값 | 기준 |
|---|---|---|
| 안산 밖으로 나가는 신고 경로 | 위치 확인 경로의 80.9% | 2026-07 배출자 신고 4,575건 집계 |
| 안산 안에서 처리 | 16.9% (2023-07 18.4%) | 신고 건수 집계 |
| 태우는 처리 대 원료 재활용 | 30.0% 대 26.7% | 신고 건수 집계, 처리업체 허가 업종 기준 |
| 같은 폐기물인데 이웃은 재활용, 우리는 소각 | 24.6% | 신고 건수 집계 |
| 공장당 처리업체 | 평균 3.07곳과 따로 계약 | 신고 건수 집계 |
| 안산 사업장 배출시설계 폐기물 | 발생 68만 4,718톤, 위탁처리 48만 8,361톤, 매립 15만 5,396톤 | 2024 공식 통계 원값 |
| 안산 지정폐기물(의료 제외) | 발생 25만 6,678톤, 위탁처리 25만 4,201톤 | 2024 공식 통계 원값 |

흐름 비율은 신고 건수 집계이며 톤수가 아닙니다.

## 해결

| 기능 | 하는 일 |
|---|---|
| FIT MAP | 안산 공장 폐기물이 지금 어디로, 어떤 방식으로 가는지 지도로 보여 줌 |
| FIT 점수 | 같은 폐기물을 이미 재활용으로 보내는 이웃 공장 수, 거리, 처리 방식으로 재활용 처리업체를 점수화해 상위 3곳 추천 |
| GROUP FIT | 같은 폐기물을 신고한 인근 공장(반경 2km)을 묶어 공동 수거와 공동 계약 |
| FIT REPORT | 공장에는 고시 단가 기준 현재 처리비, 시에는 안산 안 처리 비율과 소각, 매립에서 재활용으로 바꾼 경로 수를 보고 |

## 핵심 흐름

홈 → 1분 진단(품목, 실제 계량 무게, 위치) → 결과(지금 내는 돈, 추천 3곳) → 연결 요청 → 내 공장

## 원칙과 한계

- 시연 데이터에는 실제 공개 자료의 값과 그 값을 단순 집계한 값(건수, 비율)만 넣었습니다. 추정 금액, 시나리오 단가, 대체 좌표는 넣지 않았습니다.
- 흐름은 신고된 계약 경로이며 실제 운반 실적이 아닙니다.
- 처리 방식은 처리업체의 허가 업종 기준입니다. 허가가 둘 이상이면 하나를 고르지 않고 "복수 허가"로 둡니다.
- 좌표는 주소 위치가 확인된 것만 남겼습니다(공장 1,123곳, 처리업체 32곳). 나머지는 비워 두었습니다.
- 물량은 마대 개수가 아니라 계량표나 올바로 인계서의 무게를 입력받습니다. 마대와 톤백의 공식 무게 환산 근거가 없기 때문입니다.
- 추천은 신고 경로를 근거로 하며, 실제 처리 가능 여부는 업체 확인이 필요합니다.
