# 반월시화 AI 산업공생 매칭

> VOID 2026 해커톤 · 팀 한산

한 공장의 폐기물을 다른 공장의 원료로 잇는 '산업 공생'을, 사람 대신 AI가 짝을 찾아 다시 움직이게 하는 프로젝트입니다.

## 문제
- 안산 공장 폐기물 재활용률 62.3%로 경기 평균 82.0%보다 19.7%p 낮음 (2023, KOSIS 한국도시통계)
- 반월시화는 2005~2016년 정부 생태산업단지(EIP) 시범단지로 사업성이 검증됐지만, 사람 4~5명이 짝을 찾는 구조여서 2016년 예산 일몰과 함께 멈춤
- 반월산단 50인 미만 공장 8,593곳 중 누가 누구와 맞는지 찾아 주는 곳이 없음

## 해결
사람이 하던 '짝 찾기(발굴)'를 AI로 대체하고, 성사된 컨소시엄은 정부 생태산업개발 사업으로 연결합니다.

| 기능 | 내용 |
|---|---|
| 매칭 | 배출 폐기물과 수요 공정을 거리, 물량, 품질로 연결해 후보 제안 |
| 표준화 | 법정 폐기물 분류명과 업체 표현을 같은 속성으로 통일 |
| 공동 수거 묶음 | 소량 배출 공장을 묶어 운반 경로와 비용 최적화 |
| 절차 안내 | 재활용 신고, 순환자원 인정 등 필요한 절차 안내 |

## 시연 화면
1. 안산 자원 지도
2. 공장 입력 → AI 매칭 결과
3. 공동 수거 묶음
4. 시 대시보드

## 데이터
- 안산시 사업장 폐기물 배출신고 현황 (공공데이터포털 15170508)
- 안산시 폐기물 배출자 신고현황 (안산시 사전정보공표)
- 폐기물 발생량 및 재활용률 (KOSIS 한국도시통계)
